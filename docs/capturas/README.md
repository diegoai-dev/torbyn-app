# Screenshots

[Español](README.es.md)

Screenshots of the Torbyn desktop app (0.1.9, dark theme, in English), at
1440 × 900 with scale 2 (2880 × 1800 px; the launcher is cropped to its
agent list). They use sample data: a test project made only for them
(“online store”), a `demo@example.com` account and a throwaway data folder.
The terminals run a stand-in program instead of the real tools, and say so
on screen. The block in the paths and contract screenshot is real: Torbyn's
hook produced it on a test edit.
