# Capturas

[English](README.md)

Capturas de la app de escritorio de Torbyn (0.1.9, tema oscuro, en español),
a 1440 × 900 con escala 2 (2880 × 1800 px; el lanzador está recortado a su
lista de agentes). Usan datos de ejemplo: un proyecto de prueba creado solo
para ellas («tienda online»), una cuenta `demo@example.com` y una carpeta de
datos desechable. Las terminales ejecutan un programa de prueba en lugar de
las herramientas de verdad, y lo dicen en pantalla. El bloqueo de la captura
de rutas y contrato es real: lo produjo el hook de Torbyn ante una edición de
prueba.
