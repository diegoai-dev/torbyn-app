# Capturas · Screenshots

Capturas de la app de escritorio de Torbyn (0.1.9, tema oscuro), a 1440 × 900
con escala 2 (2880 × 1800 px; el lanzador está recortado a su lista de
agentes). Usan datos de ejemplo: un proyecto de prueba creado solo para ellas
(«tienda online» / «online store»), una cuenta `demo@example.com` y una
carpeta de datos desechable. Las terminales ejecutan un programa de prueba en
lugar de las herramientas de verdad, y lo dicen en pantalla. El bloqueo de la
captura de rutas y contrato es real: lo produjo el hook de Torbyn ante una
edición de prueba.

Screenshots of the Torbyn desktop app (0.1.9, dark theme), at 1440 × 900 with
scale 2 (2880 × 1800 px; the launcher is cropped to its agent list). They use
sample data: a test project made only for them, a `demo@example.com` account
and a throwaway data folder. The terminals run a stand-in program instead of
the real tools, and say so on screen. The block in the paths and contract
screenshot is real: Torbyn's hook produced it on a test edit.
